# Índice de memoria

Una ficha = un hecho; el diario de un frente, en `historial/`. Este índice se carga en cada sesión: una línea por ficha.

- [Finito = presentabile, poi fermenta](finito-fermentare.md) — un progetto non si chiude: è finito quando si può presentare
- [Documenti = stato attuale](documenti-stato-attuale.md) — mai "prima X, ora Y"; un punto della lista si aggiorna solo quando è chiuso, mai durante le prove
- [Come usarmi meglio solo a fine sessione](come-usarmi-meglio-solo-a-fine-sessione.md) — mai in ogni risposta; pulsanti di risposta rapida solo se c'è una decisione vera
- [Login a GitHub senza GitHub CLI](push-github-senza-gh.md) — Git usa il suo gestore di login, login salvato, il push lo fa Lola; solo se il login va rifatto lo fa Rachele dal suo terminale
- [Liste: punti fatti in fondo](liste-punti-fatti-in-fondo.md) — in ogni progetto i punti fatti non si cancellano: vanno in "Punti fatti" in fondo, testo uguale + "Fatto: come si è risolto"
- [ffmpeg nel Portfolio](ffmpeg-nel-portfolio.md) — non è nel sistema ma c'è in `node_modules\ffmpeg-static`; cercare lì prima di dire che manca
- [Non supporre che non abbia visto](non-supporre-che-non-abbia-visto.md) — modifica in locale: chiedere solo "la pubblico?", mai "la guardi?"; se dice "pubblica" ha già visto
- [Provare la chat senza IA](provare-chat-senza-ia.md) — risposta finta al posto di `/api/chat` nel browser di Lola; prima un clic per saltare l'apertura, poi invio
- [Una domanda è una domanda](domanda-e-domanda.md) — "perché non hai fatto X?" = spiegare il perché e fermarsi, mai eseguire
- [Layout: parlare di bordi](layout-parlare-di-bordi.md) — proposte di layout bordo per bordo (fermo/spostato), mai "allungare/abbassare"
- [Misurare a più larghezze](misurare-piu-larghezze.md) — dove sta un elemento: misurarlo sulla pagina vera a 2-3 larghezze, mai dedurlo dal CSS
- [Iniziare non è eseguire](iniziare-non-e-eseguire.md) — "punto X" = analisi + proposta + "lo correggo?"; codice solo dopo il sì
- [Il prompt lo inserisce Lola](prompt-lo-inserisce-lola.md) — dopo l'ok sulla bozza Lola scrive nel system prompt; niente file bozza a parte
- [Suggerimenti mai primari](suggerimenti-mai-primari.md) — primario solo per l'azione principale (inviare); prove Figma da schermate a riposo
- [Commit solo righe mie](commit-solo-righe-mie.md) — prima di `git add` guardare il diff; modifiche di altre chat restano fuori dal commit
